Credit Card Financial Dashboard

Credit Card Transaction and Customer Analysis using SQL and Power BI.

Project Overview

This project analyzes credit card transaction and customer data to understand revenue, transactions, customer segments, spending patterns, and key business metrics.

Tools Used

- SQL
- Power BI
- DAX
- Excel/CSV

What I Did

- Analyzed credit card transaction and customer data using SQL.
- Extracted relevant data using SQL queries.
- Cleaned and transformed data for reporting.
- Created calculated columns and measures using DAX.
- Built two interactive Power BI reports:
  - Credit Card Transaction Report
  - Credit Card Customer Report
- Added KPIs, charts, tables, and filters to analyze business performance.

Key Metrics

- Total Revenue: 56.5M
- Total Interest: 7.98M
- Transaction Amount: 46M
- Transaction Count: 667K
- Total Customer Income: 588M
- Customer Satisfaction: 3.19

Key Insights

- Blue and Silver cards contribute a major share of overall transactions.
- Swipe is the leading transaction method.
- Bills generate the highest revenue among expenditure categories.
- Businessman customers contribute the highest revenue among customer job groups.
- Revenue varies across age, income, education, and marital-status groups.

Project Files

- SQL queries
- Customer and transaction CSV files
- Power BI reports
- PDF reports
